# Week 7 Assignment: My Notes & The Report Builder

## Files
- `my_notes.py` - writes three notes to a file, appends a fourth, reads them back and counts the lines.
- `my_notes.txt` - the generated notes file created by `my_notes.py`.
- `report_builder.py` - reads `hubs.csv`, counts passed and failed learners, calculates the average score and writes a report.
- `hubs.csv` - the learner data (name, hub, score).
- `report.txt` - the generated learner report created by `report_builder.py`.
- `README.md` - this file.

## Question
What would happen if you changed "a" to "w" in Question 1?

If "a" were changed to "w", the file would be erased and rewritten, so the first three notes would be lost. Only "I added this later" would remain, and the line count would be 1 instead of 4.
